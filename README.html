현재 실행 방법

start_hand.bat로 실제 앱을 켜세요. 이 PC에서는 카메라 1을 선택하고 ‘카메라 켜기’를 누릅니다. Chrome을 앞에 둔 뒤 V 0.6초 → 손 펴서 자세 해제 → 검지 좌우 쓸기로 뒤로/앞으로. 숫자 3(엄지·검지·중지) 0.35초 또는 F8/중단 버튼으로 중단합니다.

start_simulated.bat: 가짜 입력으로 제어 흐름 확인. 실제 Chrome에는 키를 보내지 않습니다.

.venv\Scripts\python.exe run.py --mode DEV_SIMULATED
.venv\Scripts\python.exe run.py --mode WINDOWS_REAL
.venv\Scripts\python.exe scripts/validate.py --label local-check
.venv\Scripts\python.exe scripts/build_windows.py

WINDOWS_REAL은 카메라를 켜기 전 대기합니다. G01–G14를 실제 카메라 인식 경로에 연결했습니다. 탭/페이지, 양손 줌, 원 새로고침, 엄지 북마크, 주먹→펼침 탭 복구를 지원합니다. L 캡처 요청은 인식하되 실제 이미지·캡처 저장·설정·연습은 다음 단계입니다. 키 전송과 실제 Chrome 효과/사람별 정확도 검증은 구분합니다. 검지 인식 수정 실행 파일은 실제 카메라를 포함한 개발 빌드입니다. 이 PC에서는 start_hand.bat가 카메라 1을 미리 선택해 실행합니다. 배포본은 실행 파일과 _internal 폴더를 함께 보관하세요. 최종 새 PC·사용자 검증은 남아 있습니다.

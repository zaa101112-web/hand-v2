HAND v2

손동작 단축키를 사용하는 Windows 앱의 최종 사용자 확인용 후보입니다. 브라우저 제어, 이미지·발표, 영역 캡처, 환경설정, 연습과 감도 추천을 구현했습니다.

앱 실행최신 실행 파일사용 안내최종 검증 보고서

시작하기

카메라 선택 → 카메라 켜기 → V 0.6초 → 손 펼침 → 동작 가능 → 손동작. 개발 PC의 검증된 장치는 카메라 1입니다. 숫자 3(엄지·검지·중지) 0.35초, F8 또는 중단 버튼으로 멈춥니다.

검증 범위

자동 테스트 363개 통과. 실제 카메라·모델·Qt 20분, 28,125프레임, 평균 23.44fps, 오류 0, 정상 종료. 현재 150% 배율의 캡처 10개 영역에서 실제 크기와 기준 화면의 모든 픽셀이 일치했습니다.

3명 실손 정확도, 새 Python 없는 PC, 100/125% 실제 화면 배율, 일부 현재 빌드 Chrome 재검증과 명령별 실제 지연 표본은 남아 있습니다. 기능 구현 완료와 모든 배포 게이트 통과는 구분합니다.

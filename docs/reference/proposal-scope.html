(1) 프로젝트 개요 및 설명

영화 「아이언맨」과 「어벤져스」에는 손동작만으로 컴퓨터 화면을 조작하는 장면이 등장한다. 이러한 조작 방식이 신기하고 편리해 보인다는 점에서 흥미를 느꼈으며, 영화 속 기술의 일부를 실제 환경에서 구현해 보고자 본 프로젝트를 기획하였다.

본 프로젝트는 웹캠으로 사용자의 손 위치와 움직임을 인식하여 다양한 컴퓨터 기능을 제어하는 손동작 기반 비접촉 인터페이스를 개발하는 것을 목표로 한다. 손을 좌우로 쓸어넘겨 화면을 전환하거나, 특정 손동작으로 화면 캡처 모드를 실행하고 양손의 움직임으로 캡처 영역을 조절하는 등의 기능을 구현하고자 한다.

이를 통해 일상적인 컴퓨터 작업을 손동작으로 수행하는 경험을 제공하고, 컴퓨터 비전 기술을 활용한 직관적인 상호작용 방식의 가능성과 실제 사용 과정에서의 편의성 및 한계를 탐구하고자 한다.

(2) 주요 기술 및 기능 설명

본 프로젝트는 웹캠으로 사용자의 손동작을 인식하고, 이를 화면 조작과 키보드·마우스 명령으로 변환하는 프로그램이다. Python을 기반으로 OpenCV, MediaPipe, NumPy, PySide6, PyAutoGUI, MSS를 활용하며, 무료로 사용할 수 있는 오픈소스 도구를 중심으로 구성한다.

① 실시간 손 인식 및 동작 분석

OpenCV를 이용하여 웹캠 영상을 입력받고, MediaPipe Hand Landmarker로 손가락과 손 관절의 위치를 추적한다. NumPy를 활용하여 손가락 사이의 거리, 손의 이동 방향, 양손 사이의 거리 등을 계산한다. 이를 바탕으로 집기, 쓸어넘기기, 손바닥 펼치기 등의 동작을 판단한다. 사전 학습된 손 추적 모델을 활용하되, 동작을 구분하고 명령으로 연결하는 로직은 직접 구현한다.

② 손동작 기반 화면 및 객체 조작

프로그램 내 이미지·발표 화면에서 다음 기능을 구현한다. PySide6로 화면과 전환 효과를 구성하고, 인식된 손 좌표를 화면 좌표로 변환하여 조작에 반영한다.

손동작주요 기능구현 방식
좌우로 쓸어넘기기이전·다음 사진 또는 슬라이드로 전환손의 이동 방향과 거리를 분석하고, 해당 방향으로 화면이 밀리는 전환 효과 적용
엄지와 검지로 집기사진이나 카드 선택·이동두 손가락이 가까워지면 객체를 선택하고, 집기를 유지하는 동안 손의 위치에 따라 이동
집은 양손 사이를 벌리거나 좁히기이미지 확대·축소양손 사이의 거리 변화 비율을 이미지 크기에 반영
검지로 가리키기커서 또는 발표 포인터 이동검지 끝 좌표를 화면 좌표로 변환하여 포인터 표시
손바닥을 펼쳐 잠시 유지하기조작 활성화·일시정지유지 시간을 확인하여 조작 상태를 전환하고 화면에 표시
주먹을 쥐었다 펴기전체 보기·원래 크기로 복귀연속된 손 모양 변화를 감지하여 이미지 크기와 위치 초기화

발표 포인터는 PySide6로 표시하고, 실제 마우스 커서 이동과 드래그가 필요한 경우에는 PyAutoGUI를 활용한다. 사진이나 카드의 자유로운 이동과 화면 전환 효과는 자체 프로그램 내에서 구현한다.

③ 손동작 기반 브라우저 단축키 실행

Windows의 Chrome을 대상으로, 인식한 손동작을 PyAutoGUI의 키보드 입력 기능과 연결한다. 이를 통해 키보드를 직접 누르지 않고 페이지 이동, 탭 전환, 확대·축소 등의 기능을 실행한다.

④ 손동작 기반 화면 캡처

지정한 손동작을 일정 시간 유지하면 캡처 모드를 실행하고, PySide6로 화면 위에 반투명 선택 화면과 영역 테두리를 표시한다. 양손의 엄지와 검지를 집은 위치를 사각형의 대각선 꼭짓점으로 사용하여, 손을 움직이면 캡처 영역의 위치와 크기가 조절되도록 한다.

영역 지정 후 확정 동작을 수행하면 선택 화면을 숨기고, MSS로 해당 영역을 캡처하여 PNG 이미지로 저장한다. 취소 동작을 수행하면 저장하지 않고 캡처 모드를 종료한다. 손동작으로 영역을 자유롭게 조절할 수 있도록 자체 캡처 인터페이스를 구현한다. MSS 화면 캡처 공식 예제

⑤ 모드 구분 및 인식 안정화

동일한 손동작이 여러 기능에 사용되므로 이미지·발표 모드, 브라우저 모드, 캡처 모드를 구분하여 현재 모드에 해당하는 명령만 실행한다. 예를 들어 주먹을 쥐었다 펴는 동작은 이미지·발표 모드에서는 화면 초기화로, 브라우저 모드에서는 닫은 탭 복구로 처리한다.

또한 좌표 보정으로 손떨림을 줄이고, 동작 유지 시간과 명령 실행 후 대기 시간을 적용하여 의도하지 않은 실행이나 중복 실행을 방지한다. 현재 모드, 인식한 동작, 조작 활성화 여부를 화면에 표시하여 사용자가 프로그램의 상태를 확인할 수 있도록 한다.

(3) 개발환경

본 프로젝트는 Python 기반의 데스크톱 프로그램으로 개발하며, 최종 실행 및 검증 대상은 Windows 11로 설정한다. 코드 작성과 손 인식 로직 개발은 macOS와 Windows에서 진행하되, 운영체제에 영향을 받는 단축키 입력, 마우스 제어, 화면 캡처 기능은 실제 Windows 환경에서 테스트한다.

팀원 간 개발환경 차이로 발생하는 오류를 줄이기 위해 공통으로 사용할 Python 및 주요 라이브러리 버전을 정하고, 의존성을 requirements.txt로 관리한다. 초기에는 단일 모니터 환경을 기준으로 개발하며, Windows의 화면 배율에 따른 포인터 위치와 캡처 영역의 정확성을 확인한다.

프로그램은 웹캠 영상과 손동작을 사용자 PC에서 처리하는 방식으로 구성하며, 별도의 유료 API나 클라우드 서버 없이 개발한다. 최종 Windows용 실행 파일 제작과 동작 검증은 Windows 환경에서 진행한다.

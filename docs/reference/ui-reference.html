HAND ZIP · 화면 디자인 참고 기록

사용자가 디자인 참고로 지정한 ZIP을 정적으로 읽었습니다. 앱·설치 스크립트·다운로드 스크립트를 실행하지 않았습니다. 기능 규칙은 새 설계가 우선합니다.

확인한 화면 요소

  • 1280×860 기본 창, 흰 상단 헤더, HAND 청록 로고, 활성 상태, 카메라 버튼과 중단 버튼.
  • 왼쪽 180px 메뉴: 제어 화면 / 손동작 안내 / 연습하기 / 환경설정.
  • 브라우저와 이미지·발표를 고르는 카드형 버튼.
  • 큰 카메라/이미지 영역과 오른쪽 현재 동작·최근 명령 카드.
  • 작은 상태창, 연습의 단계·진행률, 감도 추천 후 직접 적용.

새 설계에서 교체하는 내용

  • 손바닥 시작·주먹 중단 → V 시작·숫자 3 중단.
  • 마우스/커서·클릭·끌기·창 크기 조작 → 명령과 단축키 안내.
  • 커서 표적 따라가기·커서 감도 → 제스처 성공/보류 이유·유지/재무장·인식 감도.
  • 양손 V 캡처 → 양손 L 프레임 시작, 영역은 물리 마우스·키보드로 선택.
  • 막연한 성공 메시지 → 인식/승인/전송/실기 확인 단계 구분.

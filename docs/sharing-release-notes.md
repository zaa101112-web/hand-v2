# HAND v2 M08 · 최종 확인용 후보

Windows용 손동작 단축키 앱입니다. 브라우저 제어, 이미지·발표, 영역 캡처, 설정, 연습, 감도 추천을 포함합니다.

## 다운로드 및 실행

1. Assets에서 **HAND-v2-M08-20261117-r2.zip**을 다운로드합니다.
2. 압축을 모두 풀고 **HAND-v2.exe**를 실행합니다. `_internal` 폴더를 함께 보관하세요.
3. 카메라 선택 → 카메라 켜기 → V 0.6초 → 손 펼침 → 동작 가능 → 손동작.
4. Chrome을 앞에 두고 본문에 포커스를 둡니다. 뒤로/앞으로는 방문 기록이 있어야 합니다.
5. **F8 / 숫자 3 손모양 / 중단 버튼**으로 중단합니다.

동봉된 **사용안내.html**에서 전체 기능을 확인할 수 있습니다. `Source code (zip)`은 실행 파일이 아닌 개발용 소스입니다.

## 검증 상태

자동 테스트 363개, 실제 카메라·모델·Qt 20분 안정성 검사, 현재 150% 화면의 캡처 10영역, 최종 EXE 카메라·정상 종료와 ZIP 무결성을 확인했습니다. 20분 검사에는 가상 출력을 사용했습니다.

사람별 인식 정확도, Python 없는 별도 새 PC, 실제 100/125% 배율, 실제 명령별 지연과 일부 Chrome UI 재검증은 남아 있습니다. 따라서 **Pre-release(사전 배포)**로 공유하며 전체 배포 검증 완료판으로 표시하지 않습니다.

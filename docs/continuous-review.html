2026-11-21 · 최종 사용자 확인용 후보. 경량 헥사고날·생성자 DI·TDD를 유지했습니다.

변경한 동작

  • 양손 확대·축소: 두 손의 엄지와 검지를 집고 간격을 벌리거나 모읍니다. 집기를 유지한 채 간격을 더 바꾸면 다음 단계가 실행됩니다. 기본 추가 변화 15%, 단계 간 최소 200ms입니다.
  • 뒤로가기·탭·페이지 이동: 검지/V 동작 끝에서 잠깐 멈춘 뒤 다음 동작을 이어서 합니다. 매번 손을 펼치지 않아도 됩니다. 일반 명령 간 600ms와 새 준비 구간을 적용합니다.
  • 정지 자세, 즉시 반동, EMA 잔여로 명령이 반복되지 않게 했습니다. 손 유실/대상 변경 시 양손 기준을 새로 잡으며 STOP·실행 직전 Chrome 확인은 유지합니다.
  • 북마크 창의 명시적 계속, 주먹 전환의 시작 시점 준비 여부, 캡처 저장 확인은 유지합니다. 원 동작도 끝에서 잠깐 멈추고 새 원을 그립니다.

최종 카메라 평가 방법

연습하기 → 카메라 켜기 → 연속 동작 8과제 측정을 누릅니다. 준비 3초 동안 V로 시작하고 5초마다 바뀌는 과제를 따릅니다. 뒤로/앞으로·이전/다음 탭·페이지 아래/위 6회, 양손 확대/축소 각 2단계로 총 10단계입니다. 화면의 인식과 가상 실행 수를 비교하고 누락·다른 동작·중복을 확인합니다. 결과 JSON에 과제별 원시 명령과 설정이 포함됩니다. 연습은 실제 Chrome을 조작하지 않습니다.

가상 예시·설정 변경·카메라 끄기·중단은 진행 중 측정을 무효로 만듭니다. 기존 3명×명령별20회, 개인 80%·합산 90% 목표를 이 1회 평가로 대체하지 않습니다.

개발 기록과 전달

D41–D45 추가 5 MD 범위로 검증·커밋합니다. 실제 5일을 소요했다는 뜻이 아닙니다. 기존 M08 GitHub 배포는 보존하며 이 후보는 codex/continuous-gestures 브랜치에 기록합니다.

시험 중 발견한 Qt 콤보의 문자열/Enum 변환, UI 시각보다 늦게 도착하는 카메라 표본 집계, 중복 패킷의 재집계를 검사·수정했습니다. 종료 감시 시험의 20ms 파일 기록 여유는 200ms로 조정했고 제품 종료 제한은 변경하지 않았습니다.

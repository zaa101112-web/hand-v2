프로젝트 안내검증 결과

HAND v2 사용 안내

손동작으로 Chrome 단축키를 실행하고, 이미지를 넘기거나 화면의 선택 영역을 저장하는 Windows 앱입니다.

1. 시작과 중단

  1. HAND 실행. 실행 파일과 _internal 폴더를 함께 보관하세요.
  2. 카메라를 선택하고 카메라 켜기를 누릅니다. 개발에 사용한 이 PC에서는 카메라 1이 확인되었습니다.
  3. 손 전체가 영상 중앙에 보이게 하고 V를 0.6초 유지합니다. 시작 후 손을 펼쳐 동작 가능 표시를 확인합니다.
  4. 매 동작 후 손을 펼쳐 다시 준비합니다. 잠깐 자세를 잡은 다음 쓸어도 됩니다. 손을 내렸다는 이유만으로 제어가 꺼지지는 않습니다.
  5. 숫자 3(엄지·검지·중지)을 0.35초 유지하거나, 중단 버튼 / F8으로 중단합니다. F8 등록 실패는 화면 상단에 표시됩니다. Esc는 HAND 창 안에서 중단합니다.

2. Chrome 조작

Chrome 창을 앞에 두세요. 뒤로/앞으로는 방문 기록이 있는 탭에서 작동합니다. 주소창이나 메뉴에 포커스가 있으면 본문을 한 번 클릭한 뒤 사용하세요. HAND의 작은 상태창으로 인식·실행·재무장 상태를 볼 수 있습니다.

손동작기능
검지만 펴서 왼쪽 / 오른쪽으로 쓸기뒤로 / 앞으로
V를 왼쪽 / 오른쪽으로 쓸기이전 / 다음 탭
V를 위 / 아래로 쓸기페이지 위 / 아래
양손 엄지·검지를 집고 간격 벌리기 / 좁히기한 단계 확대 / 축소
검지로 원 그리기새로고침
엄지만 펴서 0.6초 유지북마크 창 열기. 창을 닫은 뒤 작은 상태창의 계속을 누르고 손을 펼쳐 재무장합니다.
주먹 0.25초 → 1.2초 이내 손 펼치기닫은 탭 복구
양손 L 모양을 서로 마주 보게 0.8초 유지영역 캡처 시작

‘OS 키 전송 완료’는 키를 보냈다는 뜻입니다. 페이지가 실제로 바뀌었는지는 별도로 확인하세요. 물리 키를 누르고 있거나 다른 앱이 앞에 있으면 입력을 보류합니다.

3. 이미지·발표

제어 화면에서 이미지·발표를 선택하고 파일 또는 폴더를 엽니다. PNG/JPG/JPEG, 방향 정보와 투명을 지원합니다. 파일 이름의 숫자 순서로 정렬하며 손상 파일은 제외 목록에 표시합니다. 취소하거나 유효한 파일이 없으면 기존 목록을 유지합니다.

검지 좌우 쓸기 또는 ← / →로 이전·다음 이미지, 양손 집기 또는 + / −로 확대·축소, 주먹→펼침 또는 0으로 화면 맞춤을 실행합니다. 이미지별 배율은 유지되고 첫/마지막에서 멈춥니다. 앱 버튼도 같은 기능을 사용합니다.

4. 영역 캡처

  1. 양손 L, 영역 캡처 버튼 또는 HAND 안에서 Ctrl+Shift+S를 사용합니다. 버튼과 키보드는 제어 대기 중에도 사용할 수 있습니다.
  2. 실제 마우스로 드래그하거나 방향키로 영역을 고릅니다. 방향키 1px, Shift 10px, Ctrl은 오른쪽/아래 끝점 크기 조절입니다. 전체 화면 버튼도 사용할 수 있습니다.
  3. 확인 / Enter를 누르면 그 시점의 화면을 PNG로 저장합니다. 최소 크기는 실제 32×32px입니다. 저장 순간 HAND 창들은 숨겨집니다.
  4. 기본 저장 위치는 Windows 사진 / HAND-v2입니다. 환경설정에서 바꿀 수 있습니다. 성공 후 실제 파일 경로를 표시합니다.

취소 버튼은 이전 모드로 돌아갑니다. Esc·F8·숫자 3·중단 버튼은 제어를 대기로 돌립니다. 저장 작업이 이미 시작됐다면 중단 후에도 파일이 생길 수 있으며 결과 경로를 그대로 안내합니다. 실패 후 재시도는 현재 화면을 다시 저장합니다.

5. 연습과 감도 추천

연습하기에서는 실제 카메라를 쓰면서도 Chrome 키 입력이나 캡처 파일을 만들지 않습니다. 시작·자세 해제·좌우 쓸기·양손 확대·중단을 연습할 수 있습니다. 카메라가 없다면 명시적인 가상 동작 예시로 흐름만 확인하세요.

감도 추천은 검지를 편 채 정지 5초, 손 펼침을 사이에 둔 왼쪽 10회·오른쪽 10회를 수집합니다. 흔들림·좌우 편차가 크거나 표본이 부족하면 추천을 보류합니다. 현재 값과 추천 값을 비교한 뒤 저장 및 적용해야 바뀝니다.

6. 설정과 문제 확인

환경설정에서 카메라·미리보기·쓸기 거리·평활화·양손 집기·저장 폴더·로그 수준을 바꿀 수 있습니다. 카메라 변경 후에는 대기 상태에서 다시 시작하세요. 설정 저장에 실패하면 기존 적용 값과 파일을 유지합니다.

  • 카메라가 보이지 않으면 다른 카메라 번호를 선택하거나 카메라를 사용하는 다른 프로그램을 종료한 뒤 다시 켭니다.
  • 관절은 보이지만 자세가 불명확하면 손 전체와 손바닥이 정면에서 보이게 하고, 검지 외 손가락을 편안히 접으세요. 쓸기 후에는 손을 펼쳐 재무장합니다.
  • 설정과 진단 로그는 %LOCALAPPDATA%/HAND-v2에 있습니다. 로그에는 카메라 영상·Chrome 내용/URL·사용자가 입력한 문자를 저장하지 않습니다.
  • 프로그램 폴더를 옮길 때 EXE 하나만 복사하지 말고 폴더 전체를 복사하세요. Python 설치 없이 실행하도록 묶은 파일이며, 별도 새 PC 검증은 아직 남아 있습니다.
이 빌드는 최종 사용자 확인용 후보입니다. 사람별 손 인식 정확도를 보장하는 수치로 자동 테스트 결과를 읽지 마세요. 실제 검증 범위와 남은 항목은 검증 보고서에 구분했습니다.
